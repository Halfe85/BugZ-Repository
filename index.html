BugZ Repository

One repository. Two platforms.

Install addons on Kodi or server plugins on Jellyfin. Each platform has its own official catalog format, update process, and packages.

Kodi 20+

Kodi addons

Install the BugZ Kodi Repository, then select the modified Otaku video addon.

repository.bugz-1.0.0.zip

  1. Kodi → Settings → File manager → Add source.
  2. Enter https://halfe85.github.io/BugZ-Repository/ and name it BugZ.
  3. Add-ons → Install from zip file → BugZ → repository.bugz-1.0.0.zip.
  4. Install from repository → BugZ Kodi Repository → Video add-ons → Otaku.

The Kodi update catalogs and versioned ZIP files remain in kodi/. Kodi documentation.

Jellyfin Server 12

Jellyfin plugins

Install JellyTaku through Jellyfin's built-in plugin catalog. Current published version: 0.0.7.0.

  1. Jellyfin Dashboard → Plugins → Repositories (or Manage Repositories).
  2. Add a repository named BugZ with the manifest URL below.
  3. Under Plugins → Catalog, find JellyTaku and install a compatible version.
  4. Restart the Jellyfin server after installation.

Open Jellyfin manifest.json

https://raw.githubusercontent.com/Halfe85/BugZ-Repository/main/manifest.json

The Jellyfin plugin releases are stored in packages/. Jellyfin documentation.

Kodi Python addons are not Jellyfin server plugins; the two systems intentionally use independent packages. Source and release files: GitHub: Halfe85/BugZ-Repository.

Installation page requires GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). The raw GitHub-hosted Jellyfin manifest and Kodi update catalogs do not require Pages.
