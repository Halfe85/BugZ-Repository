BugZ Kodi Repository

Install the BugZ repository in Kodi, then browse its video add-ons and updates.

Download

  • repository.bugz-1.0.0.zip — Kodi repository installer

Install directly in Kodi

  1. Open Settings → File manager → Add source.
  2. Enter https://halfe85.github.io/BugZ-Repository/ and name it BugZ.
  3. Open Add-ons → Install from zip file → BugZ.
  4. Select repository.bugz-1.0.0.zip.
  5. Open Install from repository → BugZ Kodi Repository → Video add-ons.

Requires GitHub Pages to be enabled for this repository (Settings → Pages → Deploy from a branch → main → /root).
